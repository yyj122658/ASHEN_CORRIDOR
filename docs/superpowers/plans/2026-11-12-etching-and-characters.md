# 蚀刻法、纹路与角色呈现

按用户已授权的整体设计继续直接实现，不重置存档，不增加职业属性。

- UI 统一称「蚀刻法」「纹路」，精简解释性段落。工坊左栏优先蚀刻法，中心实际装配，右栏纹路；角色选择置于顶部。
- 拖拽格子使用 SVG 实际屏幕变换计算尺寸，覆盖受高度限制、缩放、旋转与滚动场景。
- 瘢痕保留格面标记；鼠标在该格停留约 550ms 后显示来源、正负属性和激活状态。焦点与触屏点击也可查看，不再常驻瘢痕列表。
- 角色展示恢复人物立绘，金属形态只在装配时显示。已有六张立绘加十五位新角色图集，共 21 位固定来客；招募不重复抽到已拥有角色。新档最多 21 人，旧档重复角色与资产保留，不妨碍收齐 21 种身份。
- 蚀刻法总量扩展到 21 种，使用现有真实战斗效果构成追击、多段、贯穿、灼烧、护持、回能、强化和混合打法。合格撤离按完成深度开放相应池，优先带回尚未拥有的蚀刻法。
- 验证：新增领域回归与拖拽像素对齐/延迟悬浮/人物图集检查，更新原浏览器测试，实际截图检查桌面与手机。

新角色立绘使用内置 imagegen 生成一张 4×4 图集，前十五格为角色，第十六格留空；在 UI 用 SVG 视窗取图，保留原图，不做位图裁剪。
