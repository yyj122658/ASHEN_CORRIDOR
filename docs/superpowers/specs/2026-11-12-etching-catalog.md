# 蚀刻法与角色清单

游戏内名称按用户要求统一为蚀刻法。内部 manuscript ID 保留，避免破坏存档。

## 同板合修

同一传奇可以装入多门不同的蚀刻法。每门拓片占据独立的格子，底层纹路可以与拓片同格。板面和总负荷共同决定能装多少门。移动、旋转和卸下只作用于选中那一门。卸下首门时，下一门递补。

首门决定平攻与基础余裕节奏，所有招式共用该传奇的余裕。每门按自己的纹路方向、覆盖、贯通和招式条件判定出手。阶位属性取已装最高阶，避免叠加生命和攻击倍率。旧档中的单门蚀刻法仍在原位。

铁鸦、磐石、灰烬、低语、烛火、暗巷、断齿、冷炉、旧钉、褪色、长夜、哑钟、霜线、赤砾、雾灯、缄书、乌隼、苔衣、铅月、余烬、白棘。

外观独立于数值与打法。新档避免同身份重复招募；已有旧档重复角色仍完整保留，不占满身份收集池。初始四人，其余通过火塘招募获得。
