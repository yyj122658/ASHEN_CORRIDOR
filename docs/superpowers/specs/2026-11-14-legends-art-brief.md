## 1. 为什么要分东西，而且不止东西

世界观里同一块生命金属有两套正名，因为有两个学派：苍梧（东洲）的《铁相录》从旧书里摘词，
问「**它像什么**」；奥伦（西洲）圣髑院的《圣铁登记册》按形制归档，问「**它该归入哪一类**」。

**名字跟着人走**：东边来的人说「象笏」，西边来的人说「竖带」，指的是同一块板。
营地里七东七西，所以你听得到两种叫法混在一起。这不是翻译差异，是谁信哪一套。

但「东／西」对画师来说太粗。总纲里两块大陆各有三个国家，做派完全不同——
**钧天的制式、琉光的矿尘、朔方的皮革，是三种人；圣髑院的旧礼服、沃尔芬的产线、碎片地带的拼贴，也是三种人。**
所以这份规格按**六国**写，不按两边写。

一条总则：**东边的人是「用旧了的东西」，西边的人是「修过很多次的东西」。**
前者磨损是自然老化，后者磨损是反复修补。这句话在六国里各有各的走法：

| | 磨损的走法 | 一句话 |
|---|---|---|
| 钧天 | 齐整到不合身 | **发的不是铁，是练法。** 铁是他自己的，练法是总局的——他穿制式的、练统一的，只有那块铁是私有财产 |
| 琉光 | 被矿吃掉的 | 尘、塌陷、把石头换成钱 |
| 朔方 | 跟着身体走的 | 皮革、骨、毡，一件衣服穿到它认得你；**连那套发下来的东西都没有** |
| 格雷沙姆 | 撑着的体面 | 旧礼服还在，金线散了，规矩没散 |
| 沃尔芬 | 换过的零件 | 补丁比原布多；炼金术在这里是专利，可买卖、可授权，就是不能白学 |
| 碎片地带 | 拼起来的 | 两件衣服缝成一件，缝在外侧，不遮 |

> **画的时候先记住一条：那块活金属长在身体里，谁也发不了、换不了、配不了。**
> 下面表格里的「金属」一栏，一律指**身外之物**——甲片、工具、佩件、仪器。
> 钧天能发给一个人的只有三样：练哪一门、怎么练、腰牌上那个登记号。
> 这个号跟大洋对岸圣髑院的《圣铁登记册》是同一件事：两边政府都没能造出一块铁，只造出了一套纸。

## 5. 逐人简述

### 苍梧 · 钧天（发下来的，不是长出来的）

**铁鸦**（总局 · 铁路押运组）——制式短褐，对襟，**腰牌上一串登记号**（这是钧天唯一的纹样：它给一块天生长出来的铁建档、定价、发例钱），
腰后制式短刃，小腿缠布，头绕灰布；一枚押运铜牌，押的是谱箱——全国统一的那一版功法就在里面。
瘦长、装备少而贴身。**不要鸟头、不要羽毛披风**——旧稿的乌鸦意象去掉，「鸦」是他做的事，不是他穿的东西。
他的一切都是发的，只有那双眼睛是自己的。主色：总局灰 + 靛。

**冷炉**（拓版铸坊）——铸版工。厚围裙、单臂皮护套、光头或紧束发、小臂旧烫疤，体型最厚。
手里一把**干活的小锤**（不是战锤）。围裙上有厂徽和车间编号，背后是熄了的炉。
他铸的是**拓版**——钧天把功法做成统一教材，全国要用的那一版得从母版上刷下来，他就是铸母版的人。
「浑沌未凿」的实体：他印了一辈子别人的字，自己的那块铁一窍没开。主色：暗铁 + 熄了的火橙。

**褪色**（被大纲刷下的旁支）——曾经在体制内。穿的是**旧的制式外衣，但徽记摘掉了，缝线痕迹还在**——
这是他身上唯一的信息量，别用别的东西去补。洗到发白的短褂、宽檐笠。赤脚。
**全队唯一一个「颜色被洗掉」的人**，别人可以有饱和色，他不能。主色：褪青 + 米白。

### 苍梧 · 琉光（把石头换成钱）

**断齿**（采空区 · 东南缘塌陷带）——矿工出身的残兵。**左肩护甲缺失**（相名的来处：缺一角，塌方压掉的），
短镐插在腰后，缺一颗牙；厚毡帽、矿灯、脸上有洗不掉的粉尘，膝盖磨破。
「地不满东南」的实体就是他缺的那只肩。主色：铁锈橙 + 土黄 + 高原赭。

**赤砾**（矿产新贵 · 只剩一条细脉）——新贵家的人，难处在**衣服料子好、但样式过时了**：
他有钱，没传承，所以穿得像三十年前的体面人。宽腰带把腰束细（「楚腰」的实体）、
头巾遮住口鼻以下、弯刀、铜臂环（矿主家传的，唯一值钱且旧的东西）。主色：砖红 + 沙黄 + 一点铜。

### 苍梧 · 朔方（跟着身体走的）

**灰烬**（萨满帐 · 唤血不成）——弓手。毡斗篷散开、**角弓**（草原复合弓，不是长弓）、发髻松垮、
下巴有旧刺青（唤血失败的记号，褪了一半），脸颊与手背有灰。剪影要能被一眼认成一张弓。
朔方不修功法修血脉——他的金属唤不醒，所以他把弓练到了尽头。主色：炭黑 + 暗红 + 毡白。

**霜线**（极北针叶林 · 垒台体修）——北地体修，与诺德海姆那套同源。毛边厚氅、缠布护腕、
鼻梁冻伤疤、长刀横在腰后；氅子下摆结霜；**背上有木架/背架**（九层之台是一层层垒上去的，
他的强是垒出来的，不是悟出来的）。主色：霜白 + 灰蓝 + 松针绿。

### 奥伦 · 格雷沙姆（撑着的体面）

**磐石**（圣髑院 · 北塔）——誓约守卫。**旧礼服残件**罩在锁甲外：肩线还在、金线已经散了、
袖口 frayed。袍上只有一枚极简的十字（**不要纹章、不要家徽**）。手持**上宽下尖的塔盾**
（这一件必须是那个形状，它是相名的实体）。站姿最正。主色：石灰 + 靛蓝 + 一点旧金。

**低语**（圣髑院 · 下厅检定台）——检定师，不是告解神父。深色工作长袍、兜帽半垂遮住上半脸、
**单眼一只黄铜检定镜**（可翻转的镜片组，这是他吃饭的家伙）、腰间一串钥匙、一只小铜匣、一叠登记卡。
**脸只需露出下半**——他是「给器物做检定的人」，不是「被看的人」。主色：黑 + 暗紫 + 黄铜。

**长夜**（圣髑院 · 地库方厅）——守夜人。厚呢斗篷、宽檐帽、手持长杆灯，胸前挂一只铜哨和一串**地库钥匙**。
他守的是一间**没有窗的方厅**（「凿户牖」是他自己凿的窗，所以斗篷上有方厅的灰、手上有一把凿子）。
帽檐下只看得见下巴和胡茬。主色：深灰蓝 + 灯黄。

### 奥伦 · 沃尔芬（换过的零件）

**暗巷**（军工企业 · 外包车间）——被大厂专利卡死的技师，后来偷东西。
工装背带裤的残件、护目镜推到额上、皮带上挂满撬锁片和小齿轮、手上有镟床的油。
蹲姿，重心低，边缘全是零碎小件。主色：褐 + 铜绿 + 油黑。

**旧钉**（船厂 · 铆接流水线）——铆工。背心或上身半裸、缠布、骨瘦、脊柱明显。
**背上是成列的旧铆钉疤——已经被皮包住，不流血**（**不要新鲜伤、不要撕裂伤**）。
手里一柄长铆枪。相名「栉比」就是这排钉：像梳齿一样整齐地排在背上，一个也不少。主色：苍白 + 暗褐 + 铁青。

### 奥伦 · 碎片地带（拼起来的）

**烛火**（双烛堂 · 东式器物接西式符文）——**一件衣服是两件缝的**：半边交领、半边罩袍，
接缝在外侧，看得见针脚和一线红线。白巾包头、双手**各持一支**蜡烛（对称的两点，对应「并蒂 / 双耳瓶」）。
面容年轻但疲惫。她本身就是碎片地带的作品：两套体系长在同一个人身上。主色：烛白 + 暖黄 + 拼缝红。

**哑钟**（路口 · 一座不响的钟楼）——钟被拆去铸炮了，他守着一座空楼。
肩披**用拆剩的钟罩铁皮改成的短披**（形似钟口）、颈上缠一段断掉的钟绳、手掌厚茧、指节粗大。
他站在一个四岔路口中央（「四达之衢」），四个方向都空。
嘴部正常（**不要缝嘴、不要面罩**）——「哑」是他的选择，不是刑具。主色：铜绿 + 焦褐 + 路尘灰。

## 7. 和代码的接口

- 国别与出身存在 `data.js` 的 `SKINS[].home / .origin`；族属 `culture` 由 `HOME_SIDE[home]` 推出来，
  **不单独写**——写两遍迟早把琉光的人标成西边。
- `homeOf(skinId)` 取国名，`originOf(skinId)` 给出「国 · 单位」一句话（招募卡与角色详情已经在用）。
- 界面按族属选相名：`bodyStyle(bodyId, culture)`；`cultureOf(skinId)` 查这位传奇用哪套。
- 悬停提示同时给两套叫法，`ui.js` 的 `styleTip()`。
- 图集格序由 `portraitCell % 4` 决定，`wanderer0..7` 的顺序**不能动**，动了所有立绘会错位。

## 8. 自查

改完对着这张表核四件事：

1. **能一眼分出两国吗？** 随便抽两张，不看脸只看布和光，能说出「一个是被发的、一个是被矿吃的」。
2. **每人身上有没有那一件「相名实体」？** 磐石的塔盾、断齿缺掉的肩甲、赤砾被束细的腰、烛火的两支烛、
   旧钉背上那排钉、褪色拆掉徽记后的缝线——这些不是装饰，是玩家把名字和画对上的唯一线索。
3. **六国有没有串味？** 钧天的人身上不该出现补丁和骨珠，朔方的人不该穿制式布签，
   沃尔芬的人不该出现在格雷沙姆那种暖色轮廓光里，碎片地带的人**必须**看得出是拼的。
4. **碎片地带的人是不是太「设计」了？** 他们的拼贴是穷出来的、补出来的，不是造型师配的——
   接缝要丑，红线要露，两半的档次可以不一样。
