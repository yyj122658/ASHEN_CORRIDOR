# 灰烬回廊 · 完整体验设计

用户授权整体设计并要求精细、美观、简洁、符合活金属设定，有持续吸引力和构筑深度。沿用原生 JS/CSS/SVG/Canvas 与现有像素资产，不更换框架，不重置存档，不提交或发布。

## 统一玩法

金属本体与瘢痕是底层，功法是可移动的透明纹路拓片，刻印填在拓片上。功法不与刻印争抢同一物理槽位；刻印之间仍禁止重叠。同向覆盖增加共鸣，完整入口到出口贯通再增加收益。普通装配可逆，营火蚀刻留下持久的格子正负属性与来源。

战斗能量表示当前共振余裕，其恢复不代表从外界增加生命金属材料。不引入离线死亡、氪金压力或额外寿命管理。

## 玩法深度来自已有选择

- 初始队伍具备三种入门功法：快攻后撤、追击前插、护持援护。角色不靠职业面板区分，打法来自所修功法，同一形态可换练法。
- 功法原有贯穿、连击、治疗、护盾、灼烧、临时强化与共享冷却必须真实执行。四个身位都可使用本门平攻与招式。战中换位会改变承伤对象和穿透覆盖。
- 覆盖率和贯通既影响战斗效果，也有可读的预计收益；新档入门功法有可用的对齐刻印，不要求玩家先猜出隐藏规则。
- 完成的远征提供功法成长、构件与瘢痕的组合选择。维持七层三选一、2/4/6层祝福和自愿撤离的风险取舍，先让现有循环可信，不新增平行成长系统。
- 战利品和商队停止产出退役武器；模板与实际奖励一致，确认幂等。

## 界面层级

营地：真实形态队伍、所修打法、是否已共鸣和一个清楚的下潜入口。工坊：选功法→填同向刻印→查看即时收益→保存；把底层瘢痕与当前纹路分层，隐藏无关旧端口术语。保留点击和拖动两种输入。

远征地图：七层进度、当前风险池、三条路线各自预期收益、明确撤离收益。战前：敌方意图、我方功法与开战阵形。战斗：环境舞台、清晰生命/共振余裕、当前招式状态；日志默认折叠。战后：每人的伤害/治疗/承伤与共鸣状态，给出从本次战斗实际数据得出的调整提示。结算：收获、所得功法、角色经历与下一次目标。

视觉保持深炭绿、灰银、古铜与余烬；不采用高饱和光污染。文字层级、空态、危险操作、焦点、窄屏和减少动效在所有页面保持一致。沿用精细像素环境，把美术预算用在实际画面需要的地方。

## 验收

测试必须证明合法异形装配能达到共鸣、招式描述与战斗一致、来源模板奖励无错、旧档不丢资产。固定种子比较不同布局/打法与连续远征的结果，记录时长、胜败和剩余生命；用真实浏览器走新档装配、战斗、重整、营火与撤离。全页面覆盖桌面与窄屏，实际截图检查。自动模拟不能证明真人一定觉得好玩，最终需试玩反馈，但不以此替代本轮可运行交付。
