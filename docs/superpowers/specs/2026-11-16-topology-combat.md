# v4.0 拓扑战斗：脉冲谐振与回路熔断（2026-11-16）

> 面板不再是「攻/防/血」，而是**从装配的纹路拓扑编译出来的五个量**。
> 核心一句：**天赋是形状，战力是接线。**

---

## 1. 五个量的新语义（字段名全部保留，兼容 `ui.js` / `view.js`）

| 旧语义 | v4.0 语义 | 怎么来 |
|---|---|---|
| `maxHp / hp` | **结构完整度** | `25 + 占格×2.5 + 闭环×12` |
| `atk` | **输出脉冲幅值** | 恒为 10（心核基座 P0），靠路径幅值乘算放大 |
| `def` | **回路阻抗** | `覆盖率×20 + 储能格×2 + 闸系格×3` |
| `shield` | **电容缓冲池** | 上限 = `储能格 × 6`；没有储能纹路就是 0 |
| `spd` | **心核节拍频率** | 底盘唯一还带差异的项 |

`derive.js` 只剩一个 `chassis(body)`：裸装就是 25 / 10 / 0 / 0 / `10 + 速度偏移`。
`ANCHOR`（140/28/12）与 `rarityStat`（阶位膨胀）已删除 —— 高阶层只是刻得更深，不是天生更大。

## 2. 六族纹路如何改规则

| 族 | 规则 | 数值 |
|---|---|---|
| 直导 | 路径每格 → 出招间隔 | −4%/格，上限 −30% |
| 弯折 | 每次 90° 转折 → 幅值 | +12%；回钩（hairpin）再 +20% |
| 分流 | 单股拆多路 | ×0.65；下游重新汇合成闭环 → ×1.45 |
| 储能 | 缓冲上限 + 受击截留 | 每格 +6 上限 / +2 阻抗；截留 30%；满溢后下一击 ×2.5 放电 |
| 闸系 | 逻辑门放大器 | 压力 ≥50 或身上有缓冲时 ×1.65；每格 +3 阻抗 |
| 余烬 | 热电转换 | 每次脉冲吸 2 点压力，再按当前压力每点 +1.5% 幅值，附带 `burn` |

实现在 `circuit.js` 的 `pulseOf()`：它拿 `Manuscript.route()` 回溯出的**唯一路径**（不是 visited 集合，
集合里带着岔路，数不出拐弯次数）逐格归属到族，产出 `{straight, turns, hairpin, split, looped, capacitors, gate, ember, intervalScale, ampMult}`。

## 3. 面板编译（`Circuit.compile`）

```
maxHp    = 25 + round(有效占格 × 2.5) + 闭环数 × 12
def      = round(主修覆盖率 × 20) + 储能格 × 2 + 闸系格 × 3
shieldCap= 储能格 × 6
atk      = 10
spd      = 底盘节拍
```

`compile()` 现在返回 `{ panel, pulse }`：`panel` 是上面五个量，`pulse` 是每门蚀刻法各自的路径特征。
`Roster.stats()` 只是「compile 出裸面板 → 叠激活瘢痕 → 乘本局生命修正」。

**踩过的坑**：`preview()` 与 `panelOf()` 在 `placements` 为 `undefined` 时会当成空板面（`[]`），
结果所有人的完整度都退成 25 的裸心核。现在两处都回落到「场上布局 → 板面布局」；
传 `[]` 仍然是明确的「空板面」。

## 4. 受击四步链路（`applyDamage`）

```
Step 1  阻抗拦截：`intercepted = round(dmg × def/(def+30))`
        拦截量 50% → 压力（废热）；装了储能再 50% → 余裕（回充）
        DOT 与穿刺（`pierce`）不走这一层
Step 2  电容截留：储能纹路把 30% 直接充进缓冲，然后缓冲吸收剩余
Step 3  外围熔断：单次 >12 的非穿刺直击，烧掉一枚还没熔断的外围纹路，整下挡掉
Step 4  完整度扣减：没有保险丝或带穿刺，才扣 hp
```

熔断之后是**轻量重编译**：阻抗 −2、缓冲上限 −6、脉冲幅值 ×0.95（不回头重跑整张图）。
敌方没有板面纹路，用 `outerNodes`（精英 1~2、首领 2~3）当同一件事：先爆壳，再掉核心。

> 阈值从规格的 15 下调到 12：在 25~120 的新尺度里，15 点只有首领打得出来，
> 实测熔断率是 0 —— 机制等于不存在。改成 12 之后，「小兵不会磨损保险丝、首领的正面撞击会」。

## 2. 结果：目标没达成，原因是一个探针层面的结构性问题

F49 目标 45~65%，实测 **A 0% / B 100% / C 78%**。

查下来根因不在数值，在**模拟器的板面根本不贯通**：
`buildBoard` 的贪心只按「覆盖多少格」选件，蚀刻法的入口/出口格没有对应开口，
`Manuscript.route()` 返回 `ok: false`，于是 `pulse.path` 恒为空 ——
直导缩间隔、弯折增压、直导闪避、闸门、余烬这些**全部来自路径**的机制在模拟里一律不触发。

实测证据（A 流派单个单位）：

```
pulse = {path: [], straight: 0, turns: 0, ampMult: 1, dodgeBonus: 0}
真实战斗里 dodge = 0.05（只有底盘基础值，直导那 +2%/格 一点没吃到）
```

这意味着本轮调的 `corner 1.5x / overload 1.85 / gate 1.45 / ember 温控 / 直导闪避`
在**引擎里是对的**（单测逐条守住了），但在**模拟器里是空转的**：
A/B/C 的差异其实来自血量、阻抗、放电这些不依赖路径的量。

同一原因也解释了「枯竭击杀 0」：`energy` 相关机制没问题，是样本里没人被抽干 ——
但更根本的是，这三套预设连自己该有的输出曲线都没跑出来。

## 3. 结论与下一步

- 数值改动**保留**（符合规格，单测证明生效）。
- 「三流派在 F49 收敛到 45~65%」这一目标**不能靠继续调数值达成**，
  必须先修模拟器的铺板器：需要在 `buildBoard` 里沿着蚀刻法的 vein 逐格铺「开口对得上」的件，
  让 `route()` 成立。否则每一轮调参都是在测「谁的血更厚」。
- 修好铺板器之后，本轮这些机制（直导闪避、余烬蓄热、闸门、放电、破甲、打断）才会真正进入归因统计，
  那时再谈收敛才有意义。

# 四标：把「通路」真的接上（2026-11-16 深夜）

## 1. 判据（先读后写）

`Manuscript.route()` 的连通判据是三条，缺一不可：

1. 相邻两格**彼此开口**：A 朝 `d` 有口，B（`d` 方向的邻居）朝 `opposite(d)` 有口；
2. 通路**只能落在蚀刻法自己的格**里（`good = 对齐格`，`if (!good.has(nk)) return`）；
3. 起点必须满足 `veins[entry] ⊆ 端口`，终点满足 `veins[exit] ⊆ 端口`（`matchesEnd`）。

由此推出一条此前没人注意的**结构约束**：
多格纹路（elbow / capacitor / hairpin…）的端口只在两端，中间格**没有任何口**，
所以它们**永远不可能出现在通路上**。能当通路格的只有「单格 + 同格给出双向端口」的四种件：

| 件 | 家族 | 端口 | 角色 |
|---|---|---|---|
| `rivet` | straight | W/E 或 N/S | 直连 |
| `jack` | straight | 任意一对正交方向 | **拐角但仍算直导** |
| `flint` | ember | 任意一对正交方向 | 余烬拐角 |
| `pinValve` | threshold | W/E 或 N/S | 闸系直连 |

这解释了上一轮为什么怎么调都是 0%：`buildBoard` 铺的是 `straight/elbow/splitter` 这类多格件，
入口格上根本没有口 —— 通路在第一个格子就断了。

## 2. 布线器（`autoRouteBoard`，`tests/helpers/veteran-run.cjs`）

三步：

1. **枚举姿态 × 落点**：`orient(4 转 × 2 镜像)` × `Manuscript.placements()`，
   长方形在 rot 0/2、1/3 下形状相同，用签名去重砍掉一半。
2. **端口受限 DFS**：从 `entry` 出发，每步只接受「端口覆盖 `{opposite(来向), 出向, 起始格 vein}`」的单格件；
   到达 `exit` 时要求端口覆盖 `{来向反面, 出口 vein}`。每条候选都用真实 `route()` 复核
   （BFS 可能走出一条更短的支路，所以打分只看 BFS 的实际结果）。
3. **余格填充**：先盖蚀刻法剩余格（换覆盖率→阻抗），再铺整板；按流派给族配额
   （elbow 最多 3 件储能、ember 最多 4 件余烬/3 件闸系），预算 = `cap ×(1+overload) − 通路负载 − 蚀刻法自身负载`。

流派权重只影响「同功能选谁」与「通路形状」：直导堆格、弯折堆转角、余烬挂 ember/threshold。

**踩到的两个坑**

- 预算漏了 `preview` 里的 `load += ms.load`（蚀刻法自己也吃负荷）→ A/B 稳定超载 3~5 点。
- 储能件按「件」配额而不是「格」：一件 `bellowsCell` 占三格，按格配会直接爆缓冲上限（实测 shieldCap 108）。

## 3. 结果：贯通 100%，但强度全面溢出

```

通路画像：A 直导 6.0 格 · 转角 4.0 · 闪避 17.0% · 幅值 ×2.07 · 间隔 0.34s
          B 直导 7.0 格 · 转角 5.0 · 闪避 19.0% · 幅值 ×1.90 · 间隔 0.29s
          C 直导 0.0 格 · 转角 7.0 · 闪避  5.0% · 幅值 ×1.84 · 间隔 0.50s
```

|---|---|---|---|---|---|---|---|---|---|---|
| A 直导 | 100% | 3.9 | 2.0 回 | 3.7 回 | 3.0 回 | 7.0 回 | 0.00 | 0.00 | 0 | 6% |

   F49 只要 2.2 回合 —— 这家的自我强化回路是最需要下一个削的。

**下一步（留给数值轮，本轮不动）**：要么压玩家侧出手频率（`autoAttack.interval`/直导上限），
要么抬敌人节奏（`enemyPace` 3.8 → 更低），两者都动会回到「双方都快」的老问题。

# 六标：节奏修正、多格中继、77 格面积重塑（2026-11-17）

## 1. 节奏：把「看得清」和「还有压力」拉回同一个刻度

`autoAttack.interval` 0.50 → **1.10s**（每秒一跳）。单人对敌人的行动比因此从 16:1 收到约 3.8:1，
整队四人约 5:1。**没有同步加速敌人** —— `enemyPace` 仍是 3.8，敌人跟着自己的间隔一起变慢。

## 2. 流派正交：`jack` 归位

`jack`（折角纹）从 `straight` 家族挪进 `elbow`：一格之内从侧缘折向上缘，本来就是一次 90° 转折。
留在直导系里，等于让「堆转角」的流派同时白拿直导的攻速和闪避，A/B 永远分不开。

直导系同时收紧：**每格 −3%（上限 −20%）**、闪避 **+1.5%/格（上限 +12%）**。
余烬的压力增幅**封顶 +30%**（每点 0.5%），并且 `waist` 的高热与 `threshold` 闸门改成**加算**：
两件同时开是 +90%，不是 ×1.45×1.45=×2.10。

## 3. 多格中继：`internalChains`

`Manuscript.internalChains(cells, ports)` 是这一步的全部秘密：从 `in` 端口格沿件内四邻接格
BFS 到每个 `out` 端口格，把链上相邻格互相开口。于是 `long / rail / elbow / hairpin / capacitor`
第一次能**穿体而过**当通路节点，而不是只能铺在通路之外。

`pieceIndex` 与布线器共用这一个函数（绝对坐标 / 相对坐标各传一次，逻辑一份）。
布线器因此能「一次落整件」：从件的出口继续走，而不是一格一件。

顺带修掉一个隐患：原来 `pieceIndex` 对没有 `paths` 表的件会**连上件内所有相邻对**，
`cistern` 那种 3×2 会被连成一张网，通路可以随便斜穿、转角数也就没意义了。

## 4. 80 门骨架重塑（面积阶梯）

`SKELETON_LADDER` + `skeletalMatrix()`：

| 稀有度 | 门数 | 格数 | 负荷 |
|---|---|---|---|
| R1 | 20 | 6–9 | 2 |
| R2 | 20 | 10–14 | 3 |
| R3 | 20 | 16–21 | 4–5 |
| R4 | 12 | 23–29 | 6–7 |
| R5 | 6 | 32–39 | 8–9 |
| R6 | 1 | 44 | 11 |
| R7 | 1 | 54 | 12 |

生成方式：选一个贴合的包围盒 → 从**走廊**（4–6 格，带 0~4 次转折）出发 BFS 生长 →
「补满 2×2」的格子按 50% 概率跳过，于是骨架里自然散着 1×2 / 2×2 的镶嵌槽。
走廊决定入口→出口的形状，枝体只挂在出口上，不会替通路造捷径。

**面积一变，另外三件事必须跟着动**（都做了）：

1. `hpPerCell` 2.5 → **1.15**（满铺落在 60~100）；
2. `generatedCapPerCell` 0.26 → **0.72**（77 格 → 55 点，否则大卷永远压不满）；
3. 窄底盘上大卷放不下 → `fitToPlate()`：宽板用原样，窄板按「含入口的最大连通块」裁剪，
   语义是「这块金属刻不下整卷」。装配第二门时按「别人占掉之后剩下的格」浇铸。

**开局也必须通电**：`Circuit.autoLoadout()` 沿骨架铺一条 entry→exit 的最短路
（每格一件 rivet/jack/flint/pinValve），`State.create` 发现预设板面接不通就先把它退回仓库再铺。

## 5. 又补了一个封顶：转角

骨架变大后通路能到 20+ 格，转角跟着涨到 24 次，`1 + 24×0.12 = ×3.9`（三隅再乘 1.5 → ×5.38）。
直导有 −20% 封顶、转角却没有任何上限，这是不对称的。补 `PULSE.turnCap = 8`（最多计 8 次转折）。
