# 灰烬回廊 · 玩法现状交接（给外部 AI 的背景包）

> 目的：把「现在这套玩法长什么样、数字是多少、哪里确定有问题」一次说清，方便外部模型直接给方案，不用猜。
> 所有数字来自 `src/veteran/data.js` 与 `src/veteran/combat.js` 实算（`node scripts/etching-inventory.cjs`），不是估算。
> 生成时间：2026-11-15。分支 `feat/terms-and-combat-timing`。

---

## 1. 一句话

《灰烬回廊》是一款**暗黑风格的远征 Roguelike**：你带一支小队下七层回廊，每个人身上有一块天生的「活金属」，你往里装配成套的**功法**（游戏内现称「蚀刻法」），在时间轴上打即时制战斗，出来结算、改装、再下去。

---

## 2. 最小必要世界观（决定了很多机制为什么长这样）

- **生命能量 = 一块活着的金属**。它天生是什么形状，你一辈子就只能长成什么样；它在空气里自然生锈，锈满即死。
- **修行 = 抛光 + 留纹**：正确共振会磨掉锈、并在金属上永久留下纹。所以「用力量」不是消耗资源，而是变强。
- **三层可传递性**（这是最硬的边界，改机制时不能违背）：
  1. **金属天生**——77 格、什么形状，娘胎里带的。造不出、补不了、换不了。
  2. **功法可发可传**——国家、宗门、企业都能发、能教、能卖、能申请专利。玩家装配的东西属于这一层。
  3. **纹刻不出来**——知识可以言传，手上一道纹只能自己磨，不能复制、不能继承。
- 一句话：**制度能规定你练什么，不能替你练成什么。**
- 世界有两块大陆、六个国家：苍梧（东，走功法）三国 = 钧天/琉光/朔方；奥伦（西，走炼金术）三国 = 格雷沙姆/沃尔芬/碎片地带。十四位传奇七东七西，出身决定他用哪一套名字叫同一块铁。
- **术语坑**：世界观里「蚀刻法」是**原理层的规律名**（纹如何形成/加深/覆盖/断裂），可装配的那 80 门其实是**功法**。目前游戏显示层仍叫「蚀刻法」，是已知待改项（backlog B4）。

## 3. 当前系统与数值

### 3.1 金属板面（角色本体）

| 项 | 值 | 说明 |
|---|---|---|
| 板面 | 12×12 网格，取 **77 格** | 每个人格数相同，差别只在**形状** |
| 形状 | **14 相**（浑沌未凿 / 象笏 / 凿户牖 / 四达之衢 / 鉴燧之齐 / 地不满东南 / 悬针 / 楚腰 / 并蒂 / 轮牙 / 玄璜 / 九层之台 / 溯洄从之 / 栉比） | 每相有固定轮廓身份（长条、缺角 L、细腰、十字、内环…），边缘碎格随机 |
| 面板 | 由「相」的四项权重派生 | 锚点 生命 140 / 攻击 28 / 防御 12 / 速度 10；没有一相是纯优势 |
| 负荷上限 | **20**（= 77 格 × 0.26） | 装东西要占负荷。2026-11-15 从 44 压到 20，理由见 §5 ① |
| 可同时维持 | **4 门** | 硬上限 `DESIGN.manuscriptSlots` |
| 瘢痕减免 | 1 处激活瘢痕 = −1 负荷 | 营火烙印留下的永久纹不再需要维持 |

### 3.2 战斗（时间轴）

| 项 | 值 |
|---|---|
| 步长 | 0.24s；6 步 = 1 回合（1.44s） |
| 普通攻击 | 基础间隔 0.5s，倍率 0.55；可被功法改（`intervalScale` / `mult` / `extraHits`） |
| 余裕（能量） | 基础回 1.0/s，上限 20；招式消耗余裕，按秒回 |
| 招式 | 有 `cost`（余裕）/ `castTime`（引导，期间不普攻）/ `cooldown` |
| 防御 | 一次行动，减伤 **80%** |
| 位置 | 前排/后排共 4 位，可战中换位 |
| 压力 | 0–100 双向：≥50 回裕 ×0.85、伤害 ×1.10；≥80 回裕 ×0.65、伤害 ×1.25 |
| 压力 100 | **临界判定，一场一次**：75% 裂（满压红利翻成 ×0.85、受伤 ×1.25、抛光 ×0.70，带进下一场直到安抚）／25% 砺（压力退回 50、抛光 ×1.20，不留痕） |

### 3.3 装配的三个概念（这套关系的核心）

1. **纹路**（30 种零散零件）：铺在板面上，占格、给方向与增益。
2. **功法**（80 门成套路线，现称「蚀刻法」）：**压在纹路上**，自己占格、自带出入口（`entry`/`exits`）。
3. **覆盖 / 共鸣阶 / 贯通**：
   - **覆盖** = 功法的格子落在「已被纹路占用」的格上的百分比。
   - **共鸣阶** = 覆盖达标就上一档，给主修乘算（`mainMult`）。门槛多为 **50% / 100%**（54 门是这两档，26 门是 40/80/100 之类）。
   - **贯通** = 从入口沿双方都开口的格子走到出口，额外 ×1.15。
4. **装配完全可逆**：卸下无损，原件回库、腾出门数、不留痕。有损的只有「营火烙印」（把捡到的纹路真刻进去，留下一格不可逆的瘢痕）。

## 5. 已确认的问题（按严重程度）

### ① 负荷上限太宽（**已修一半**）

原状：平均 5 格 / 2.2 负荷；板面 77 格、负荷上限 44。装满 4 门也只吃约 20 格、9 点负荷——超载永远触发不了。

**2026-11-15 已改**：77 格的负荷上限压到 **20**（系数 0.57 → 0.26），并删掉「每点负荷 +3% 主修乘算」的返利（它会让重功法自己抵掉成本，方向恰好相反）。现在装第三、四门重功法时会真的顶到线，`过用则裂` 有机会发生。

**仍未解决**：格数还是不疼。四门平均只占 20 格 / 77 格，14 相的形状差异（长条、缺角、细腰、内环）依然感觉不到。下一个要动的是「格形」本身，不是数值。

### ② 「80 门」实际上是 80 个同一个按钮（**已修，2026-11-15**）

原状：79 门只有 1 个招式。已改为 142 个招式：2–3 阶各 2 招（第二招吃「目标身上有本轴异常」），
4–5 阶的第二招要 `minTier 2` **且**同轴接续，6/7 阶三招递进。阶数现在真的代表「多会几手」。

### ③ 持续伤害没有种类（**已修，2026-11-15**）

原状：所有 `dot` 落成灼烧。现四种各有独特结算时机（引爆 / 随普攻 / 罚动作 / 削防增压），
功法库里供给：灼烧 16 个招式、中毒 6、流血 13、腐蚀 10。

### ④ 共鸣阶的收益偏小且门槛偏松

54/80 门用「覆盖 50% 得一档 / 100% 得二档」，满档只有 +14%~+21%。
也就是说「铺得准」这件事的回报，远小于「招式倍率」本身。位置上花的心思不划算。

### ⑤ 小问题

- **星火**（1 阶 / 2 格 / 1 负荷 / 无招式）是唯一的「纯普攻饰品」，也是唯一不带按钮的门。
- 招式条件只有 5 种（已贯通 / 敌人血线 / 普攻次数 / 余裕下限 / 有人受伤），且 76 门里条件重复率高。
- 4 门上限让「装错」只亏时间（因为拆卸无损），缺乏取舍张力。

## 6. 硬约束（改的时候不能破坏）

1. **装配可逆**：卸下无损、腾出门数、不留痕。这是世界观（功法是方案不是纹）与玩家承诺，不能为了「增加代价」去改成有损。
2. **格数恒定 77**：相与相之间只有形状差异，没有格数差异——强弱由面板权重摊平。
3. **天赋是形状，不是数值**：面板从相权重派生，不能给某相加隐藏属性。
4. **名称两套**：东用《铁相录》正名（象笏、楚腰、地不满东南…），西用圣髑院《圣铁登记册》形制名（竖带、塔盾、圣物匣…）。同一块铁两个名字，不许只留一套。
5. **测试**：`npm test` 285 条（284 通过，唯一红的是「开局难度」这条模拟，属已知问题 B5）；`npm run test:ui` 通过。改数据后跑 `node scripts/etching-inventory.cjs` 重出清单。

## 7. 想请对方 AI 回答的问题

1. **怎么让「格形」真的成为玩法？** 现有素材是 14 相轮廓 + 80 门各自固定的格形。在不新增美术、不改「77 格恒定」的前提下，有没有比「抬高负荷/格数」更聪明的做法？（例如：让相邻/方向产生额外规则、让覆盖率改成「形状吻合度」、让空缺本身有价值）
2. **一门多招该怎么组织？** 若把 5–7 阶做成 2–3 个招式，是「按共鸣阶解锁」还是「按战斗内资源解锁」？怎么避免变成「招式栏变长」而不是「打法变多」？
3. **DOT 分家值不值得做？** 把 15 门拆成灼烧/中毒/流血/腐蚀四种，能否形成真正的构筑轴？还是说 DOT 在这个「0.5 秒一次普攻」的时间轴里天生弱势？
4. **「4 门上限」该保留还是让位给格数/负荷？** 如果保留，它就是唯一约束（简单但单调）；如果让位，需要重新设计一个「装不下」的痛感来源。
5. **共鸣阶值得救吗？** 现在它是「覆盖 50% 就 +6%」，改成什么样才会让玩家愿意为了一个落点反复调整装配？
