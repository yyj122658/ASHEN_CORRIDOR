## 1. 词条解释（现有唯一成体系的「关键词」资产，ui.js:32）

- **压力**：传奇在远征中积累的紧张程度，范围 0–100。敌方招式、现场烙印或撤退会增加，休整、进食和安抚可以降低。压力是双向的：50 起自然回裕降到 85%、出手伤害 +10%；80 起回裕降到 65%、伤害 +25%。
- **余裕**：释放蚀刻法招式所用的战斗资源。每位传奇单独积攒，随时间恢复；该传奇装配的各门招式共用这份余裕，释放时扣除。
- **主修 / 合修**：装配顺序里的第一门是主修，决定普通攻击的节奏、倍率和基础余裕恢复。后面的门是合修：只提供它自己的招式，招式冷却比主修短 1 秒；它身上的纹路增益减半计入余裕上限与恢复。
- **覆盖 / 共鸣阶 / 贯通**：蚀刻法的格子落在对得上的金属格上就是覆盖；覆盖跨过门槛（如 40%/75%/100%）就上一档共鸣阶；蚀刻法自身的入口沿纹路接到出口，额外获得贯通加成。
- **共鸣增幅**：共鸣阶的乘算与贯通乘算相乘后的总加成，作用在普通攻击和全部招式伤害上，不改变招式消耗与冷却。
- **持续伤害**：中毒、灼烧、流血在受伤者自己出手之前结算，腐蚀在出手之后结算。每结算一次算一跳，跳完次数就消失；每跳之前先判死，被毒死的人当次出手直接取消。
- **营火烙印**：把本趟找到的一件纹路装进传奇的金属板面，立刻用于后续战斗。每人每趟一次，本趟生命上限降低20%，压力增加40。若落点上有未留痕的格子，其中一格会留下瘢痕。
- **瘢痕**：烙印留在格底的记录。填上纹路或蚀刻法时触发这一格的正负属性，腾空后属性休眠。指向板上的裂纹标记可查看来源和效果。
- **负荷**：装上一件纹路或一门蚀刻法占用的承载量。物品的形状决定占哪些格，负荷决定这块金属板面还承受得了多少；超出的部分照样能装，但每超 1 点开局压力 +8、自然回裕 -0.08/s。越重的蚀刻法共鸣乘算也越高（每点负荷 +3%）。

## 2. 系统名词（属性 / 资源 / 目标 / 条件 / 行动）

**属性**：生命 / 攻击 / 防御 / 速度（战斗面板另称 生命·攻击·防御）

**行动（ACTIONS）**：普通攻击、防御

**目标（TARGETS）**：正面敌人、最残敌人、最残队友、蓄力中的敌人、自己

**条件（CONDITIONS）**：总是、自身生命低于、有队友生命低于、敌人正在蓄力、自身位于

**身体**：

- **厚铸躯壳**（生命 160／攻 28／防 18／速 8）：厚甲慢步。能扛住贯穿，但上手慢。
- **轻量骨架**（生命 120／攻 28／防 8／速 14）：出手快、皮薄。余裕周转快，容错低。
- **导流腔体**（生命 140／攻 28／防 12／速 10）：居中。屏蔽格偏角，两条基础线路都能过。

**武器（主手输出）**：
- **短刃**：贴脸才狠。适合前排换位构筑。 ｜输出：2 余裕，160% 单体。只有站在 1 号位才能出手，其余位置退回 100% 普通攻击。 ｜特性「回手」：每场战斗第一次主手输出返还 1 点余裕。
- **塔盾**：不打伤害，打节奏。 ｜输出：2 余裕，100% 盾击并跳过目标一次行动。站在 1 号位时自身减伤 20%，持续到下次行动。 ｜特性「承伤」：每场战斗第一次替身保护可挡一次贯穿。
- **长矛**：站第二排也够得着。 ｜输出：2 余裕。1 号位 120% 正面单体；2 号位 120% 贯穿敌方前两位；3、4 号位不可用。 ｜特性「回手」：每场战斗第一次主手输出返还 1 点余裕。
- **重炮**：后排便宜，前排自伤。 ｜输出：4 余裕，180% 单体；站在 4 号位只要 2 余裕。1 号位开火自身损失当前生命上限 10%，不产生受击余裕。 ｜特性「回手」：每场战斗第一次主手输出返还 1 点余裕。
- **仪式杖**：把人从死亡线拉回来。 ｜输出：2 余裕，治疗生命比例最低的友军 = 170% 攻击；全员满血时改为 120% 法术单体。 ｜特性「溢流」：每场战斗首次溢出治疗转为护盾，上限目标生命上限 10%。

**防御**：不耗余裕，下一次受击减伤 80%，到下次自身行动失效。

## 5. 身法（站位特性，3 条）

- **影进**：站在第三或第四位时，普通攻击造成伤害便插到最前。每回合至多一次。
- **折光后撤**：在第一位普通攻击造成伤害后与第二位互换，并留下可挡一次直击的残影，持续到本人下次出手。每回合至多一次。
- **铁壁援护**：一次敌方行动结束后，若紧邻前方友军存活且生命低于 30%，向前交换并转移其灼烧/流血。每回合至多一次。

**祝福**：
- **锐利**：主手伤害 +15%。
- **厚重**：全队受到的伤害 -10%。
- **导通**：每场战斗开始时主手输出直接获得 2 余裕。
- **拾荒**：金币收获 +20%。
- **缝补**：每层结束时全队恢复 12% 生命。
- **禁忌契约**：主手伤害 +25%，压力获取 +25%。

## 7. 事件文本（现场 / 选项 / 结果，11 条）

### 雾中的岔路
> 雾里分出三条路。地上有血迹，也有拖痕。
- **走血迹**（提示：迎战，赢了才有东西） → 血迹尽头不是尸体——那东西还站着。它抬起头，看见了你们。
- **跟拖痕**（提示：拿到纹路，但有人受伤） → 拖痕尽头是一堆被扯开的纹路。有人被绊倒，膝盖见了血。
- **走中间**（提示：没有收获，也没有风险） → 你们走了中间。什么也没有发生，这本身就是好消息。

### 墙里的敲击
> 三下，停，三下。墙是实的，声音不是。
- **凿开墙**（提示：可能拿到纹路，也可能惊动东西） → 墙后面塞着一具旧尸，手里攥着还能用的纹路。
- **贴着听**（提示：压力降低，没有收获） → 你们听了一会儿。敲击停了。有人发现自己一直在屏住呼吸。

### 堆叠的残骸
> 一整面墙都是拆到一半的东西。有几块还在发微光。
- **翻找**（提示：拿到纹路） → 翻到一件还能用的。手指被划开一道口子。
- **不碰**（提示：什么也不发生） → 你们绕开了。身后的光慢慢暗下去。

### 冷锅
> 锅还在冒气，三只碗摆在石头边。碗底沉着几节指骨。
- **添一把料，重新分**（提示：消耗 1 份随身食材，全队回血、压压惊） → 你们把料丢进锅里，等它重新滚起来。没人去问上一桌是谁。
- **只喝汤**（提示：少量回复，压力上升） → 汤是咸的，后味发甜。喝完之后，有人一直舔自己的牙。
- **不动别人的饭**（提示：什么也不发生） → 你们从锅边绕过去。走出十几步，汤还在冒气。

### 灯蛾灯笼
> 铁笼里挤满灯蛾，翅膀把光磨成粉。笼门是用布条缠上的。
- **连笼一起收走**（提示：得到 3 份食材，压力上升） → 蛾粉落进你们的袖口，一直亮到走廊尽头。
- **就着光坐一会**（提示：全队回血、压力下降） → 你们轮流把手伸到笼边烤着。光不热，但人慢慢安静下来。
- **放它们走**（提示：不取东西，压力下降） → 布条一解开，光就散进雾里。回廊看起来宽了一点。

### 记账摊
> 摊后没有人。账页自己翻，笔尖悬在纸上，等一个名字。
- **签上名字**（提示：60 金币，换一门战利谱） → 笔尖落下去，纸面吸走了墨。柜台上多出一卷还没凉透的拓片。
- **翻几页**（提示：得到金币，压力上升） → 账上全是别人的欠款，每条后面都写着同一个日期。你们带走了一点零钱。
- **不碰别人的账**（提示：什么也不发生） → 你们走开了。翻页声在身后停了半拍，又继续。

### 骨合唱
> 十几具骸骨跪成一圈，唱一个很长的音。它们在念名字。
- **跟着哼**（提示：压力大降，本趟生命上限 -5%） → 你们跟着哼到那个音结束。有人觉得胸腔里空了一块，但心里轻了。
- **打断它们**（提示：迎战，赢了才有东西） → 你们踩进圈里。唱声断了，所有头一起转过来。
- **捂住耳朵绕开**（提示：压力上升） → 那个音跟着你们走了很久，像有人贴着后颈在念。

### 停摆的钟
> 钟停在最高处。钟舌上缠着布，布上有暗色的字。
- **解开布条敲下去**（提示：一半机会得祝福，一半全队重伤）
- **割下布条带走**（提示：得到金币，压力上升） → 布条上的字被你们折了起来。钟没有说话。
- **让它停着**（提示：什么也不发生） → 你们从钟下面走过去。影子被钟口切成一截一截。

- **再付一笔**（提示：40 金币，换 1 件遗物） → 小字被划掉了。柜台上多了一枚温热的旧币。
- **把名字擦掉**（提示：六成机会无事，四成全队受伤）
- **合上账本**（提示：什么也不发生） → 你们把账合上。它在手里还是热的，像刚被人合过。

### 深井
> 井壁上全是向上的抓痕，最深处的抓痕最新。
- **下到井底**（提示：45% 得金币与祝福，否则全队重伤）
