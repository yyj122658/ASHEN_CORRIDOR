# 远征背包

远征背包起始24格。食材按品种分堆、按外形占位，一件纹路保留自己的二维轮廓，移动或丢弃时作为一整件处理。拓本随独立拓本匣携带。

背包固定六列。谷粒占一格，每堆六份；小型食材占一格，每堆四份；叶片横占两格，每堆四份；长茎纵占两格，每堆三份；带骨肉等大块材料呈三格折角，每堆两份；巢蜜和囊体占四格，每堆三份。同类替料有各自的物品身份，只与同种食材堆叠。

灰烬前哨可以用仓库材料永久扩容，每次增加六格。编织侧袋需要灯藻3份、骨犬腱2份；加固背架需要石衣4份、骨犬腱3份、雾胶2份；折叠囊袋需要回声囊2份、雾胶4份、灯藻6份。材料不足时不会扣料。旧存档默认从24格开始。

玩家从远征页面进入背包。地图、搜刮、营火和游商阶段可以整理、换位和丢弃，搜刮时可直接将现场战利品装入腾出的格子。其他远征阶段仅供查看。键盘使用 B 打开，触屏可依次点选物品与目的格。

存档中的物品归属仍由随身纹路列表和食材数量决定。格位顺序只记录摆放，旧档按已有物品补出格位，做菜、现场蚀刻与撤离沿用各自的物资结算。

战斗胜利后直接进入双栏搜刮页。左边整理随身物资，右边的六列地面格先显示轮廓，依次搜索揭晓后可以点取战斗掉落的纹路与食材。选择「留下余物并离开」时只清理仍在现场的物品。金币、遗物与独立拓本匣沿用各自的结算规则。

普通宝箱里的所有物品一同进入现场。玩家可逐件拾取，也可以直接离开。背包给每件物品画连续的外边框；从中间格拖起时仍以原抓取点携带整件，绿色预览表示能放入，红色表示位置不合适。

地面物品辨认完成后，可以拖到左侧指定位置。纹路占据完整形状。点击食材拾取一份，拖入则按落点能容纳的份数装入，也可在空处另起一堆。落点无效时，现场余量和随身物品都保持原样。

### 搜刮现场

地面以六列摆放，至少显示八行，并在物件下方预留空行。背包、待整理区和地面之间转移物件时沿用纹路或食物的实际轮廓。放到地上的物件可以原地挪动、重新拾取，并随本层现场一起保存；离开节点时清理。待整理区有物件时，背包的空格仍可使用。

整理背包时可以选中多格物品，点「旋转 ↻」按顺时针转九十度。搜刮时也可在拖动途中按 R 改变朝向，或使用地面清单中的旋转按钮。碰撞与越界时保留原位置；背包内每堆各自保存方向，拾取并入已有堆时沿用目标堆的方向。

### 前哨仓库

食材、料理、纹路和蚀刻法分架保存，每架起始六列四行；扩建为所有货架各加两行，最多三次。安装密封匣后，食材与料理每堆多收两份。仓储布局只保存朝向与落点，库存仍由原有撤离、工坊与厨房流程管理。超额战利品进入待上架区，腾出空间后自动上架。
