# 回廊藏品扩充

本轮以可取得的内容计数。新食材沿楼层采集或按敌种采收，保留原有食材来源。单料菜支撑当层补给，合菜让玩家决定是否为下一处营火留出行囊格。

30 种纹路以生命金属表面的刻痕命名。顺丝纹横贯两格，回钩纹折返，十字星纹沿三个末端轮流传递脉动。仓库、商人、宝箱、战利品与工坊从同一份模板读取名称和效果；存档以模板 ID 识别纹路。

蚀刻法沿用撤离奖励、宝箱拓本、精英拓本三种来源，保留旧谱目 ID、共享余裕及独立触发规则。

料理手册按现有材料优先排序，可用菜名、食材名和制作记录筛选。仓库保留库存与试装入口，另设可搜索的藏品索引，供玩家查询名称、占格、效果和获取线索。图鉴收录不授予物品。
