# 灰烬回廊的界面与远征选择

前哨以队伍和出发为中心，工坊以选中传奇的金属板为中心，回廊以当前可选道路为中心。各页沿用同一条导航和操作层级。人物使用已有立绘，地点使用前哨、工坊、营火和回廊原画。

工坊左选蚀刻法，右选纹路。点击试铺会优先寻找能覆盖所选拓片的合法位置，保留其他纹路。试铺与预设均修改草稿，使用仓库及当前板面上已有的纹路。底层瘢痕继续显示在对应格子上。

宝箱提供两件不同纹路供挑选，商人展示三种不同商品。满包时沿用替换或放弃流程。宝箱选项随远征存档一起保存，旧档原有的待处理物品沿用旧流程。

桌面实机画面可参照[前哨](../verification/redesign-camp.png)、[工坊](../verification/redesign-workshop.png)和[岔路](../verification/redesign-map.png)。手机工坊在板面上方切换蚀刻法与纹路两组工具。
### 传奇的战斗动作

角色按自身身份读取原有动作图集。每位传奇的出手由预备、出手和收势三个姿势控制，轨迹绘制与角色帧使用同一条时间轴。施术、阵形换位、格挡与闪避各自消费对应战斗事件。暂停冻结动画，减少动态效果时仍播放角色图集，省略附加位移和轨迹。战斗结算独立于绘制帧率。

蚀刻法覆盖率按纹路占住的膜格计数，每格只计一次。达到覆盖台阶即可获得台阶增益。贯通单独检查膜内是否有一条连续刻线从入口接到出口，成功后攻辅倍率再乘 1.1。整件纹路的内部转角可以传导；并排折返的两股之间不能抄近路。

远征共七章，每章七个节点。岔路是同一节点的备选遭遇，章末须完成守关战才能进入下一章；每个已结算节点后都能带走背包。存档沿用连续节点编号，旧远征保留原节点、现场与战利品。章内进度条只画七格。
