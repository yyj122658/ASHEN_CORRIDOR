# 蚀刻法与纹路实装核对

按游戏内板面和负荷上限验证，每行给出一种满覆盖且贯通的摆法。同组蚀刻法可以共用这套摆法。坐标从覆膜左上角 (0,0) 起算，向右、向下递增。旋转为顺时针，翻面在旋转之前。

| 蚀刻法 | 纹路及落点 |
|---|---|
| 星火、逐隙、回息、涟回、扣钉、灰芯、锡丝、锉齿、蒲席、骨笛、针眼、犬闸 | 顺丝纹 (0,0) |
| 直贯五脉、引燃、追亡、铁壁、裂锋、鸣脉、芦矢、百叶、石鳞 | 曲折纹 (2,0)；顺丝纹 (0,0) |
| 余烬十二脉 | 垂芒纹 (3,1) 翻面 转90°；芦叶纹 (1,0) 翻面；粟点纹 (0,0)；错节纹 (0,1)；粟点纹 (2,1)；粟点纹 (0,2) |
| 重铸阔卷 | 垂芒纹 (4,1) 翻面 转90°；芦叶纹 (2,0) 翻面；顺丝纹 (0,0)；错节纹 (0,1)；曲折纹 (2,1) |
| 连刺、疾雨、潮汐、孤注、铜钲 | 曲折纹 (1,0)；粟点纹 (0,0)；顺丝纹 (0,1) |
| 双流、逆脉、震裂、守灯、回响、分砧、炉眼 | 芦叶纹 (1,0) 翻面；粟点纹 (0,0)；芦叶纹 (1,1)；粟点纹 (0,1) |
| 焊缝、碎鳞、锈锥、铅封、退火、银触、渣钩、盐裹、髓针 | 曲折纹 (0,0) |
| 风箱、淬壳、回炉、火筛、铁颚、钻芯 | 顺丝纹 (0,0)；顺丝纹 (0,1) |
| 墨斗、旱坞、悬铃 | 牵丝纹 (0,0)；粟点纹 (3,0) |
| 集露、琉钟、革扣、雾绗 | 牵丝纹 (0,0)；粟点纹 (3,0)；顺丝纹 (2,1) |
| 桨栓、钳口、簧片、肋耙 | 芦叶纹 (1,1) 翻面 转180°；垂芒纹 (0,0) |
| 绞盘、煤层、蜡版、节锤、渊阀 | 牵丝纹 (1,0)；粟点纹 (0,0)；顺丝纹 (0,1) |
| 辊花、锯岩、透镜、颌簧 | 曲折纹 (2,1)；曲折纹 (0,0) |
| 测深、叶轮、渣枪、铁昙 | 芦叶纹 (1,2) 翻面 转180°；垂芒纹 (0,1)；粟点纹 (1,0) |
| 垂烛、巡烛、盐龛 | 芦叶纹 (1,0) 转180°；垂芒纹 (0,1) 翻面；粟点纹 (1,2) |
| 磁极、双耳、炉衣 | 错节纹 (0,0)；折角纹 (3,1)；折角纹 (3,0) 转180°；粟点纹 (3,2) |
