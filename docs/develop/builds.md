# 构筑与流派

这篇是「拿到什么纹章，该走哪条路」的手册，也是 `scripts/archetype-report.cjs` 的说明。
数字全部来自那支脚本：第 28 层普通遭遇、4 个种子、只给主 C 装配（其余三人保持默认），
用来比较流派之间的相对差距，不替代四人协同的真人试玩。

```bash
node scripts/archetype-report.cjs        # 默认第 28 层
node scripts/archetype-report.cjs 7      # 也可以只看第一章
```

## 一、三条底层规则（先看这个再看表）

1. **增益按端口比例给。** 一枚纹章如果只有 1 个开口的格压在蚀刻法上，只拿 `1/开口数` 的增益；
   压满才吃全额。所以「大纹章蹭一格」不再是白嫖。
2. **五条独立轴。** 平A（`attackMult`）、招式（`skillMult`）、治疗（`healMult`）、
   灼烧（`dotMult`）、护盾（`shieldMult`）。再加能量经济（`regen/max/skillCostCut/lowHpRegen`）。
   一条轴只喂一种打法，堆错轴等于空过。
3. **贯通是几何奖励。** 覆盖率决定档位（`mainMult/startEnergy/supportMult`），
   贯通再乘 1.15 的主手与护持。它不便宜，但 14 个招式拿它当释放条件。

治疗与护盾的算式单独记一下，很容易堆错：

```
治疗量 = 攻击 × 招式 heal 系数 × 护持倍率 × (1 + healMult)
护盾量 = 目标最大生命 × 12% × 护持倍率 × (1 + shieldMult)   // 上限 30% 生命
```

**治疗不吃 `skillMult`。** 鹤颈/水滴/回钩/长脊/叠浪才是奶该堆的东西。

## 三、六条可打的构筑

实测（第 28 层，4 种子，全部 4/4 胜）：

| 构筑 | 主 C 蚀刻法 | 纹章 | 覆盖 | 结果 |
|---|---|---|---|---|
| 平A流 | 逆脉 / 连刺 | 余烬 + 日轮 + 游焰 + 火星 | 100% | 13.6s，DPS 205，平A +30%、灼烧 +32% |
| 逆脉贯通 | 逆脉 | 芦叶 + 粟点 + 芦叶 + 粟点，再补余烬/日轮/游焰 | 100% 贯通 | 13.8s，DPS 201，平A 只 +6% 就追平 |
| 灼烧流 | 连刺 / 引燃系 | 余烬 + 游焰 + 日轮 + 焰尾 | 83% | 19.4s，DPS 143，灼烧 +24% |
| 招式流 | 余烬十二脉 / 重铸阔卷 | 层岩 + 叠浪 + 鹤颈 + 双蕨 | 67% | 29.9s，DPS 93，招式 +40% |
| 治疗流 | 回息 / 潮汐 | 长脊 + 叠浪 + 回钩 + 水滴 | 50% | 33.2s，治疗 485（同场平A流只有 94） |
| 护盾流 | 直贯五脉 / 铁壁系 | 同心 + 闭鳞 + 层岩 + **护持指令** | 100% | 30.1s，护盾 89，盾 +30% |

### 平A流

主 C 只做一件事：把 `attackMult` 和点火堆起来，靠 0.5 秒一次的平A 打伤害。
余烬纹章同时给点火，所以平A流天然带一点灼烧。第 7 层的逆脉（`routedBonus 0.25`）是顶点。

### 逆脉贯通

走线配方（相对蚀刻法左上角）：芦叶纹 (1,0) 翻面、粟点纹 (0,0)、芦叶纹 (1,1)、粟点纹 (0,1)。
先确保 `routed=true` 再加增伤——逆脉的平A 在贯通时额外 +25%，这是它唯一能追平纯堆增伤的原因。
**同样的走线给直贯五脉（2 阶）就不划算**：档位太低，走线吃掉的两枚纹章不如直接堆增伤。

### 灼烧流

点火靠余烬系（命中附灼烧），跳伤靠 `dotMult`。适合连刺、引燃、火筛这类高频或带灼烧的蚀刻法。
注意灼烧是按 `atk × 系数` 算的，所以主 C 的金属阶位比纹章更决定跳伤基数。

### 招式流

层岩（上限 +5、招式 +28%）与叠浪（上限 +3、招式 +12%）是核心，鹤颈补治疗、双蕨降消耗。
缺点很明显：现在平A 仍占伤害的六成左右，招式流在同资源下比平A流慢一档。它是给
「余烬十二脉 / 重铸阔卷 / 双流」这类招式条件强的蚀刻法用的，不是通用最优。

### 治疗流

奶只堆三样：`healMult`、`regen`、档位的 `supportMult`。
回息在 50%/100% 档位各给 1.12/1.22 护持倍率，是这条流的门槛。
**不要给奶堆同心/层岩的招式倍率**，那对治疗一点用都没有。

### 护盾流

需要在编队里把主 C 的动作从「主手」改成「保护」。护持不耗余裕，4 秒一次，
给目标 12% 最大生命的盾（上限 30%），同一个人不会连着护持两次。
它的代价是**用一次行动换盾**，所以别挂成默认规则——全队都挂会变成只举盾不还手。

## 四、开局怎么选

| 先掉到什么 | 走哪条 |
|---|---|
| 两枚以上余烬/游焰/日轮 | 平A 或灼烧，看主 C 有没有灼烧招式 |
| 层岩 + 叠浪 | 招式流；有鹤颈/水滴就顺手转治疗 |
| 折叶 / 闭鳞 | 护盾流，记得改指令 |
| 逆脉 / 震裂 / 回响 / 炉眼 | 走线，先把通路拼出来 |
| 什么都没有 | 用牵丝/长脊铺覆盖率，吃档位的 `mainMult` |

具体装配顺序建议：**先定主 C 的蚀刻法 → 把覆盖率压到 90% 以上（够到顶档）→ 再补对应轴的纹章
→ 最后考虑贯通**。贯通排在最后，因为它花的是两枚纹章的位置。

## 五、别做这些

- **别用 `skillMult` 喂治疗**，算式里没有它。
- **别把大纹章只压一格**，现在只按端口比例给。
- **别为 100% 覆盖牺牲一切**：档位在 40/75/90 的蚀刻法，多出来的两格不如换成增伤。
- **别把「保护」挂成默认**：默认指令只有攻击一条，防守是玩家自己选的取舍。
- **别在 2 阶蚀刻法上走线**：走线是几何投资，低阶蚀刻法付不起这个位置成本。

## 六、眼下的短板（写在这里，免得被当成已完成）

1. 招式流仍偏弱：平A 占伤害 59~63%，招式轴吃不到平A 的频率红利。
2. 治疗/护盾的档位只有少数蚀刻法带 `supportMult`，其余奶妈仍靠 `healMult` 硬撑。
3. 走线可行但门槛高：同一副蚀刻法在不同板面 seed 上要重拼，没有一键配方。
4. 以上数字是单 C 对照，不是四人协同强度；真正的流派强弱还要靠真人试玩。
