# 回廊生态与烹饪

探索按楼层分为余光水道（1–2）、硫泉阶井（3–4）和黑炉底床（5–7）。层域决定普通遭遇与可采集的配菜。怪物的可食部位来自其肉身、附生物或巢藏，击败哪种生物决定战后能拾取什么。路线图提供栖息线索。

同种食材装入同一堆，每堆的体积和上限由材料决定，做菜和入库仍按份数结算。队伍可现场放弃采收、丢弃随身食材、在营火消耗材料做饭，或撤回据点入库。紧急撤退只保住部分食材，全灭则失去本次采收。仓库存货与当次远征行囊独立。

每处营火保留一次免费休整。前哨用仓库里的食材做菜，野外营火用随身食材做菜。每次烹饪将一份成品放入背包并记一次制作；玩家再从背包把料理交给指定传奇。野外可按菜谱效果恢复该传奇的生命、缓解压力，前哨可用餐缓解压力。料理不改变生命金属总量、纹理或瘢痕。

前哨首页和导航都能进入仓库。食材、料理、纹路、蚀刻法分栏陈列；料理栏逐份存入或装包，已装包的料理随队出发。正常撤离后食材与闲置纹路入库，剩余成品菜留在随身包。

野外营火左侧使用远征背包，右侧按当前材料与装盒空间显示能做的料理。制作期间显示锅和热气，完成后成品直接进包。前哨厨房保留完整料理手册。
