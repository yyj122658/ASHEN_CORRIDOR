# 蚀刻法与角色调整验证

## 交付

- 游戏文字统一为「蚀刻法」「纹路」，内部 ID 与存档 key 保留。
- 工坊左选蚀刻法、中间装配、右选纹路，角色切换移到顶部。去掉常驻瘢痕列表、重复教学及实现细节说明。
- 拖影格子按 SVG 的实际屏幕变换计算，已装蚀刻法和库存蚀刻法均有真实形状，支持拖动时旋转/翻转并正确保存。吸附位置与落点一致，拓片可叠在纹路上。
- 瘢痕在格面显示，鼠标停留约 550ms 查看来源、正负属性和生效状态；键盘焦点及触屏点按也可查看。
- 共二十一位来客：复用六张立绘，内置 imagegen 新增十五张半身像，保存为一张图集。营地、编队、招募、详情和战前恢复人物呈现。
- 二十一套蚀刻法均接入真实战斗与撤离获取池。详细打法见 [内容清单](../superpowers/specs/2026-11-12-etching-catalog.md)。
