## 3. 判定

| 验收项 | 目标 | 实测 | 判定 |
|---|---|---|---|
| Mix F36 | 75%~92% | **100%** | ❌ 偏硬不足 |
| Mix F49 | 45%~75% | **72%** | ✅ |
| 对角线 A 克守门人 | A 的守门人列应为最高 | **84% > 4% > 0%** | ✅ |
| 对角线 C 克噬忆者 | C 的噬忆者列应为最高 | **20% > 12% > 4%**（量级偏低） | ⚠️ 方向成立 |
| 对角线 B 克炉心俑 | B 的炉心俑列应为最高 | 16% < 守门人 84% | ❌ |
| 熔断 | 0.15~0.40/人 | 0.15 / 0.15 / 0.19（A 0.02） | ✅（A 偏低） |
| 放电 | 非零 | Mix **3.20/局** · A **3.70/局** | ✅ |
| 打断重铸 | 非零 | Mix **1.96/局** · C 1.06 | ✅ |
| 高热覆盖 | C 45%~65% | **45%**（F49 单层 56%） | ✅ |
| 枯竭停机 | 真实非零 | 主表 0.00；**噬忆者列 0.14~0.33/局**（`_probe/starve.cjs`） | ⚠️ 限定轴 |

### 逐项说明

- **A 的防御轴真的立住了**：动能护盾让 A 在 F49 的平均回合从 7.2 拉到 **15.1**，守门人列从 0% 打到 **84%**。
  副作用（好的那种）：动能缓冲把 `shield` 顶到上限，A 现在也会触发「满溢整仓放电」—— 放电指标从 0 变成 **3.70/局**。
- **B 的转角延迟生效但不够**：出手间隔 0.86s → **1.07s**（+24% 上限打满），F49 从 88% 掉到 18%（Mix F49 因此落进 72%）。
  但 B 在守门人列仍有 84% —— 它的单发 ×2.42 即使被护膜吃掉 75% 也足以清场，**这条差距不是机制能补的**（见下）。
- **C 的对角线方向对了、量级不够**：噬忆者列 20% 是 C 三列里最高的（4% / 20% / 12%），
  说明「高热免抽 + 25% 过载反冲」这条腿在起作用；但 C 的基础 DPS 仍是三家里最低的（幅值 ×2.00 / 间隔 1.10s），
  打不动 285 血的炉心俑，也抢不过 B 的忆者列（60%）。
- **F36 仍然 100%**：精英场是 3 个单位、整场挥 6~8 下，总伤害约为队伍 EHP 的 15% —— 换任何数值都只是「赢得更慢」。
  本轮把 A 的防御轴补上之后，F36 甚至从 24% 变成 100%：**这条只能靠改编成解决，不是数值问题**。

### 结论一句话

三项里 **Mix F49 落进区间（72%）**、**A 克守门人成立（84%）**、**C 克噬忆者方向成立（20%）**；
未成立的是 **Mix F36（100%，编成问题）** 与 **B 克炉心俑（B 的 DPS 比第二高流派高 40%+，任何首领都挡不住它）**。
要彻底闭环，下一轮必须先做「B 的 DPS 收 40%」或「炉心俑按承伤类型减免」这两件设计层面的事。
