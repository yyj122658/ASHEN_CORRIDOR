## 3. 为什么没落到目标区间（诊断）

四项指令全部按值落地，但敌方压强仍差一个数量级。实测三个结构性瓶颈都在**我方一侧**：

1. **完整度不是「面板」，是「填格数」**：77 格满铺 + 13 个闭环 → 完整度 270
   （`25 + 77×1.15 + 13×12`，其中闭环贡献 156）。四名 A 流派成员合计 1140，而 F49 敌方
   三人合计只有 443。敌人活得比玩家短，出手次数就被压死。
2. **阻抗拦截吃掉一半以上的脉冲**：`def 32–55` 对 `defBase 30` → 拦截 52–65%。
   F49 首领 37 点幅值打到 A 身上只剩 15，B 只剩 2–5。**熔断阈值（8% 完整度 = 12–22）
   永远高于「透进来」的伤害**，所以保险丝响不了。
3. **储能缓冲把每次受击的 30% 现充成护盾**：B 的 90–108 缓冲池在受击过程中自充，
   一场 10 回合的战斗里吃满 18 次攻击只掉 13 点完整度。A 没有储能纹路，于是
   「有 caps 就接近免疫，没 caps 就被磨死」——A/B/C 的生存不在同一量级。

## 4. 若要真正落进目标区间

纯数值标定到 F36≈80% / F49≈67%（实测可复现）需要：

```
scaling.hpPerFloor   0.06 → 0.28        （F49 完整度 ×3.24）
scaling.atkPerFloor  0.075 → 0.40       （F49 幅值 ×4.20）
minionHpMult         0.72 → 1.0         （随从不再是半血摆设）
bossMinionHpMult     0.28 → 0.9         （首领随从 26 血 → 90 血）
```

实测代价：F22 回合 12.8 → 18.1、F49 → 26.0；且 **A 流派在 F49 全灭（0/5）**，
B/C 全胜（5/5）——「三流派各有胜负」仍不成立，因为 A 没有任何防御轴
（无储能缓冲、幅值 1.24 对 2.08/1.72）。

要让 A/B/C 都各有胜负，需要先做**流派对位**（例如：给 A 一条「直导格叠闪避」
以外的减伤路径；给 B/C 一条被穿透/被 DOT 绕过的代价），再回来标定曲线。
