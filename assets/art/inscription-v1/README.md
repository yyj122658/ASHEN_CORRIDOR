# 功法素材与单色片段

交付19张：三张768×1024卷轴、一张1024×1024半透明膜、十五张256×256单色纹路片段。

根目录PNG是定尺交付版，raw/保留5份ImageGen原始输出。A/B由内置ImageGen生成；C由一份ImageGen白色笔触母版统一裁切、定宽、旋转、alpha合成，未将15张分别交给模型猜走向。完整生成提示词在PROMPTS.json，修正后的需求在../../../docs/art-request-v2.md。

C按文件名定义方向（用户确认）：N上、E右、S下、W左。RGB全部为纯白，亮度变化编码在alpha中，可直接程序染色。名义宽度20px，实际横截面宽度和边缘偏移见manifest.json。所有主动开口贴边，非主动边透明；已校验各开口中心偏移≤3px。四个单向片段的另一个端点位于中心。

B膜的alpha统一为112/255，属于半透明覆盖层；已降低材质对比，并做横纵周期色差校正，相对边RGBA像素逐点一致。A只做3:4定尺，不叠加任何文字或预置功法纹路。

prepare-assets.py记录处理过程并带验收断言，仅操作本目录。需带Pillow的Python环境。contact-sheet.html/png是原始交付文件的排版预览，膜在底材上做2×2重复显示。

未改动玩法代码或运行时映射，尚未在游戏中验收叠加、染色和缩放效果。
