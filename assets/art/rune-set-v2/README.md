## 校准与验证

沿用 scripts/prepare-runes.py 的 alpha_bbox（alpha≥64），裁切后精确缩放到 256px/格。非占格区域 alpha 清零，格外余光为 0，不超过 0.15 格。根目录文件是校准交付版本，raw/ 是未校准生成原画；运行时请使用根目录文件。

四枚纹章均检查：尺寸与整数格比、实心包围盒四边贴画布、占格/空格中心、开口附近琥珀高亮刻线距格边中点≤0.1格。扫描结果记录在 manifest.json 的 ports[].visualOffsetCells；这是图像扫描估计，接入后仍需检查实际尺寸显示效果。

底材从生成图缩放到 1024×1024，再用横纵线性色差校正使两对相对边像素逐点相等，避免只凭提示词承诺无缝。未加入边框、纹章、阴影或发光。接缝差为0，另提供平铺预览验收。

## 交付边界

manifest.json 沿用 cells / ports / mask / solidBounds，同时记录哈希、原始裁切边界、处理方式。新纹章尚无运行时规则定义，ports 中的 in/out 为本图的建议方向，不宣称已经实现分流或能量规则。格边开口位置和形状已确定，最终端口角色交由编码 agent 确认。

未输出板面轮廓图、功法膜或旋转/翻转变体。没有改动游戏代码、现有六张原画或既有 grid/；本批尚未接入游戏。

## 重现

安装 Pillow 的 Python 环境执行本目录 prepare-assets.py，会只更新本目录校准图及 manifest.json；复用现有 alpha_bbox，不修改原始图。脚本内置断言校验。

contact-sheet.html/png 为交付原图总览和 2×2 平铺预览；PNG由浏览器渲染页面得到。
