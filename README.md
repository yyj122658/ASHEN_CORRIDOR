# 灰烬回廊 · Ashen Corridor

像素风横版自动战斗。**单入口**：`index.html` 一套玩法、一份存档、一个名字。

玩法内核是「生命金属形态 + 蚀刻法 + 纹路」：开局由铁鸦和灰烬同行，可招募传奇补齐四个身位，平攻与技能由蚀刻法决定，
打不过可以无限次「重新整备」，**活着撤离东西才入仓**。
原生 JavaScript + CSS + Canvas，无框架、无运行时 CDN、无打包步骤。

2026-11-11 起，原先并行的两个版本合成一个：老的「职业 / 升星 / 羁绊 / 随机装备」玩法退役，
由「老兵回路」规则集接管入口，游戏名保持《灰烬回廊》；旧的 `ashen_corridor_v1` / `v2` 存档不再读取。

## 核心循环

营地装配 → 下潜七章（每章七个节点）→ 岔路择一，章末击败守关者 → 遭遇战可无限「重新整备」 → 每个节点结束后可携物撤离入仓。

- **选路与收获**：地图显示当前小队、背包和撤离奖励。宝箱揭示两种纹路供挑选，游商每次展示三种不同纹路。已揭示的选项随存档保留。
- **对纹试铺**：工坊选中闲置纹路后，可以优先试铺在与当前蚀刻法方向相合的位置。试铺可撤销，保存后记入角色装配。营火可从本趟带回的纹路中挑选一件烙印。

每层都有战斗和补给可选。第 2 层起可能遇到营火，第 3 层起开放精英和商人，第 7 层须击败首领才算通关。宝箱展示两种纹路，只能带走一件；若背包放不下，可替换包内一件或放弃。商人展示三种不同的纹路，按标价购买。

- **生命金属内景**：每位传奇的异形板面由固定 seed 生成。真实轮廓、可用格与连续空间决定装配条件。
- **可逆纹路**：蚀刻法与纹路可移动、旋转、翻转和拆装。蚀刻法决定平攻、技能、回裕和阵形动作；纹路改变覆盖率和贯通。
- **底层瘢痕**：格子被纹路或已装蚀刻法填充时，同时触发正负属性；空置停用，来源与痕迹仍保留。营火现场烙印会预览并留下一个瘢痕，普通拆装不额外留痕。
- 工坊板上的铜红裂纹标出瘢痕所在格，悬停、键盘聚焦或触屏点格可查来源与效果。青绿色外缘标出已装蚀刻法的覆膜；点「查看覆膜」可淡化上层纹路，单独看清膜谱。
- **共同基数**：异形板传奇不再按底盘名称附赠血防速度差异；面板与战斗共用蚀刻法阶位、激活瘢痕和本局修正。经典4×4存档保留旧基数。
- **行为指令**：条件 + 目标 + 动作，按顺序取第一条合法项，最多 AND 两个条件。不执行时界面会说明原因
  （余裕不足、指令条件未满足、没有合法目标）。
- **可逆整备**：敌人、初始种子、检查点在第一次进入节点时固定。打不过就重来，不要钱；
  改身位或指令可能改变出手顺序。
- **营火现场烙印**：把本局捡到的纹路直接烙进板面，代价是本局生命上限 ×0.8、压力 +40。
  烙进去的纹路仍算本局风险池——撤退时按获得顺序保留一半；已确认的底层瘢痕随传奇保留。
- **老兵保护**：紧急撤退保留一半新收获与全部带入资产；确认败退则失去本局新收获，
  但**不永久杀人、不扒装备**。合格撤离（≥3 层）累计解锁第 3 条指令槽。

## 运行

**方式一：双击 `index.html`**
不需要服务器、不需要联网，直接在现代浏览器（Chrome / Edge / Firefox / Safari）打开即可。

**方式二：本地 HTTP 预览**

```bash
npm run dev
# http://127.0.0.1:4173/
```

服务器只监听 127.0.0.1，拒绝路径穿越，是只读静态服务。

> 两种方式都能完整游玩。`file://` 下唯一的限制是 Canvas 读取像素会被浏览器拒绝（图片跨源），这只影响自动化测试，不影响画面与操作。

**在线试玩**：https://yyj122658.github.io/ASHEN_CORRIDOR/ （`gh-pages` 分支，只含运行时文件）

## 存档

- 存储 key：`ashen_corridor_veteran_v1`，结构 `{schemaVersion:1, ruleset:'veteran', savedAt, state}`。
- 旧的 `ashen_corridor_v1` / `ashen_corridor_v2` **不再读取、也不会被改写**，留在浏览器里。
- 损坏时不会静默抹档：原串另存为 `ashen_corridor_veteran_v1_broken_<时间戳>` 并报告 `corrupt`。
- 设置里可导出 JSON；导入会先完整校验（schema、数值范围、ID 唯一性、物品归属），通过后才替换。
- 战斗每 tick 最多每秒落盘一次，`visibilitychange` / `pagehide` 会强制刷新。
  页面被强杀时最多回退到最后一个检查点，不承诺零丢失。

- 启动只预加载 `scene.camp`（标题页与营地共用）。

## 战斗逐帧动画

21 位传奇按招募外观选择各自的动作。铁鸦与骸骨兵使用原版四组逐帧动画。其余 20 位传奇以及骨犬、石傀、扰位石傀、幽魂、守门人、噬忆者各有六幅独立姿态。弓手拉弓、缄书伸手施术、哑钟甩出链香炉；骨犬的第一幅待机沿用原骨犬图。鸣钟骨、瘦犬、炉渣傀、唱喑、拖骸者、火工与炉心俑没有专属图集，读同族立绘并叠一层色调，战场上仍能分辨。可查看[战场实拍](docs/verification/legend-battle.gif)和[21 位传奇动作对照](docs/verification/legend-actions.webp)。

| 项 | 实现 |
|---|---|
| 识别 | 传奇读取 `skinId`，敌人读取 `enemyType`，换位保留角色造型 |
| 图集 | `assets/art/battle-v1/` 保存铁鸦与骸骨兵的 PNG，`assets/art/battle-v3/` 为每个新增角色保存一条透明 WebP |
| 动作 | 待机循环，攻击与受击完成后回待机，死亡保持倒地；多段命中共用一次出手 |
| 播放 | 每帧按脚底锚点对齐，暂停与打开弹窗冻结动作，战斗倍率同步至 3 倍 |
| 恢复 | 备战时预载本场阵容与背景，直接进入战场会补载，读档时存活者待机、阵亡者留在倒地末帧 |
| 加载期间 | 战位显示角色名字与状态条 |

## 已知限制

1. **没有真人试玩计时**。10–15 分钟目标只有 tick 推算，没有实测。
2. **自动策略还不是熟练玩家**。已模拟 24 局连续远征与 48 场构筑控制实验；没有自动执行完整的跨局学习、蚀刻法升级和最优装配。
3. **战斗中关闭页面再打开** 会回到标题页（不后台推进战斗），不做战斗内断点续打。
4. **音效是合成短音**，只有点击/命中/暴击/拾取/胜负五种，没有环境音与音乐。
5. **敌人是 9 种普通、2 种精英、3 个首领**，层域编成轮转有限；亚种复用同族立绘、只靠色调区分，长线仍会有重复感。
6. **`file://` 下 Canvas 无法读取像素**（跨源污染），不影响显示与操作。
7. **未做完整的无障碍审计**：有焦点样式、`aria-live` 提示、44px 触控目标，但没有屏幕阅读器实测。
8. **动作资产仍有复用**。传奇与首领使用现有两套逐帧图集；骨犬为静态身体配合程序运动，部分敌人仍是程序绘制。
9. **46 MB 原始 PNG 未做衍生压缩**。WebP/AVIF 派生与小尺寸缩略图未做；HTTP 部署建议先出一套派生资源。
10. **旧玩法内容已随代码删除**：六职业、升星、羁绊、随机装备词条、祭坛都不再存在（git 历史可查）。

## 当前界面与内容

游戏内统一使用「蚀刻法」「纹路」。工坊左选蚀刻法，右选纹路；金属形态用于中心装配，营地、编队、招募和战前展示人物立绘。瘢痕标在格子上，鼠标停留约550ms显示详情，键盘焦点与触屏点按也可查看。

共21位固定来客、30种纹路、80门蚀刻法。46门进入撤离奖励池，另有17门宝箱拓本和17门精英拓本。拓本匣每趟容纳一份，空匣搜箱时有三分之一机会发现，击败精英可取其战获拓本。拓本随正常撤离入库，紧急撤退和败退会遗失。新档仓库提供「扣钉」和「直贯五脉」。仓库的回廊藏品索引可按效果或出处查询。

四个身位都能施展主修和合修。星火命中后可从第一位后撤；逐隙命中后可从后两位插到最前；回息可向前替换相邻的低血同伴。敌人按换位后的阵形选择目标。压力达到 50 或 80 时，每秒自然恢复的余裕分别降低 20% 或 40%。

同一传奇可以同时装多门不同的蚀刻法。首门决定平攻与基础余裕，各门招式共用余裕，各自判断覆盖、贯通与招式条件。每张拓片独占一片金属，纹路可以压在拓片上；总负荷在所有拓片和纹路之间分配。卸下首门时由下一门递补，格底的瘢痕记录保留。

蚀刻法透明拓片可与纹路叠放，覆盖、贯通、战中换位、治疗条件、共享冷却与强化均接入战斗。长说明与重复提示已精简，玩法收益保留在当前选项及悬浮详情中。

## 敌人与事件

三个层域各有自己的打法：余光水道教你别只顾前排，硫泉阶井要你先拆结构，黑炉底床同时考续航与收尾。普通九种、精英两种、首领三个；首领按开局局数轮换，半血后进入第二阶段并追加招式。

普通敌人只靠一句能说清的行为区分：鸣钟骨给全队上眩光，瘦犬绕过前排咬后排，炉渣傀倒下时崩壳，唱喑替同族续命。精英是一个更厚的本体加随从，不是把三个普通怪血量乘小。亚种复用同族立绘，用色调区分，机制完全不同。

遇到的事件按层解锁。每条事件两到三个选项，代价有金额、食材、成菜、纹路、生命上限和压力；不满足门槛的选项直接禁用并写明差多少。赌局用存档里的种子掷，同一状态重放结果一致。收益都落到真实系统：食材与成菜进背包，战利谱进拓本匣，祝福进本趟加成，生命上限进本趟修正。每条事件都留一条无门槛出口，不想赌也能走完。

## 构筑与流派

纹章增益按「对上的端口比例」结算：一枚纹章只压住一格，只拿一份，压满才吃全额。所以板面上的每一枚都要算位置，而不是先摆上去再蹭。

增益分成五条独立的轴：平A、招式、治疗、灼烧、护盾，另外还有能量经济（恢复、上限、消耗、残血恢复）。治疗量与护盾量各吃自己的倍率，招式倍率喂不到治疗——奶妈要堆鹤颈、水滴、回钩、长脊，不是同心。

贯通在覆盖率之外再给主手与护持 ×1.15。逆脉这类「平A 吃贯通加成」的蚀刻法，走线能和纯堆增伤打平；直贯五脉这类低阶蚀刻法走线就不划算，位置成本收不回来。

指令里的主手、保护、防御现在都真的会执行：护持不耗余裕、4 秒一次、给目标 12% 最大生命的盾；防御换掉一次出手，下一次受击减伤 20%。默认指令只留攻击一条——把护持挂成默认，全队会在挨打时一直举盾不还手。

## 回廊食材

远征中点「背包」或按 B 打开行囊。同种食材自动堆叠，堆满后另占位置。纹路按实际外形占格。拖动换位，或先点物品再点目的格。背包满时可在搜刮现场丢掉物品，腾出空间带走新的战利品。回到灰烬前哨后，点「背包改装」，用带回的材料把初始24格行囊逐步扩至30、36、42格。

三个层域共有120种食材、77道料理。七种敌人和三个采集地点各有十二种产物，每次获得基础食材及一份同源伴生料。食材与纹路共用六列行囊。前哨厨房和野外营火做出的料理先进背包。把料理拖给队员，或点选料理后点队员，即可定向用餐。前哨仓库分别陈列食材、料理、纹路和蚀刻法，料理可以存入仓库或取出带走。缺少指定材料时可使用同类替料，料理手册显示这次实际消耗的食材。可以按菜名、食材名、材料齐备情况和烹饪记录筛选。[生态与野炊规则](docs/develop/corridor-kitchen.md)
